OkColorPicker — Windows x64

START

Run the Windows x64 setup executable and open OkColorPicker from the Start menu.
Setup installs the app for your account. If required, it downloads and verifies
the Microsoft Visual C++ v14 x64 runtime and installs it quietly. Windows may
request administrator approval for this component. A DirectX 12-capable GPU
and a current graphics driver are required.

UPDATES

When a newer release is ready, choose Install now or Install on next launch.
The picker closes for the update and reopens after installation unless a restart
is required. Your color library and settings stay in your profile.

PICK COLORS

Choose sRGB, Display P3 or Rec.2020 as the working gamut. Drag the lightness/chroma
slice or use the L, C, H and alpha bars. Edit a numeric value and press Enter.
Up/Down adjusts a focused number; the wheel works over the focused number.
Shift makes larger steps and Ctrl makes finer steps. Escape cancels a draft or drag.

Outside text entry, Ctrl+C/V copies or pastes a complete color. Ctrl+Z undoes;
Ctrl+Shift+Z or Ctrl+Y redoes. Inside text entry, clipboard shortcuts edit the text.

The picker preserves the original numeric color even when previewing or copying
a mapped sRGB color. Check the preview status and Mapped/Clipped output setting.
Wide-gamut output depends on the Windows display mode and the monitor.

CONNECT A PAINTING APP

The default install folder is %LOCALAPPDATA%\Programs\OkColorPicker. It contains
Painting-plugins.zip and OkColorPicker.lua for the apps that need them.

Right-click the status bar connection button to choose an app. Left-click the
abbreviation to connect or disconnect. The selected app is saved.

CSP: In CLIP STUDIO PAINT, display the Companion Mode QR code (Connect to
smartphone). Click CSP in the picker while the code is visible. If scanning
fails, copy the pairing URL from the QR code and click Paste pairing link.

PS, Ai, Id: Start Photoshop, Illustrator or InDesign, then click its button.
Illustrator needs an open document. The picker writes the current
foreground/background pair to Photoshop. In Illustrator it updates default and
selected fill/stroke. In InDesign it updates two named swatches and the
default fill/stroke and selected frames. Connecting while an object is selected recolors the object.

Krita: Extract Painting-plugins.zip. In Krita, use Settings > Manage Resources
> Open Resource Folder. Copy krita/okcolorpicker.desktop and the accompanying
okcolorpicker folder into pykrita. Copy OkColorPicker.gpl into palettes.
Enable OkColorPicker under Settings > Configure Krita > Python Plugin Manager.
Restart Krita, open a document, then click Krita in the picker. The plugin
synchronizes brush foreground and background on local port 9011.

Ob: From Painting-plugins.zip copy obsidian/okcolorpicker into the vault's
.obsidian/plugins directory. Enable OkColorPicker in Settings > Community
plugins. Click Ob in the picker. Place the cursor on a six-digit hex color in
a note, or select a Canvas card or edge. Color edits synchronize on local
port 9010. Use the editor context menu to wrap selected text in a text or
background color, or choose automatic wrapping in the plugin settings.

Ase: In Aseprite 1.3 or later, use File > Scripts > Open Scripts Folder.
Copy OkColorPicker.lua from this package there, rescan the scripts folder,
then choose File > Scripts > OkColorPicker. Click Ase in the picker and allow
the script to connect locally if prompted. Both color slots are synchronized.
Close the script dialog to stop the Aseprite connection.

Reb: Start Rebelle 8 Pro with these command-line arguments:
-websocket-server-enable -websocket-allowed-ip-addresses 127.0.0.1
Click Reb in the picker to send the selected color to the brush on port 8265.

With an Adobe app, Aseprite or Krita connected, choose Send palette in the
Harmony tab to append its colors to the destination swatches or palette.
Send swatches in Picker or APCA exports colors in the open folder, or unfiled colors at the top level.

SAVED COLORS

Committed colors, recent colors and preferences are saved in:
%LOCALAPPDATA%\OkColorPicker\state.json
Undo history lasts for the current session. Uninstall OkColorPicker through
Windows Settings > Apps > Installed apps. Your colors stay in your profile.
